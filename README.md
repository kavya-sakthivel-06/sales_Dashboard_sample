The main objective of this project is to develop an interactive Excel dashboard that provides a comprehensive overview of luxury cosmetics sales performance and answers key business questions such as:

Which products and categories generate the highest revenue?
Which brands contribute the most to overall profitability?
Which regions have the strongest sales performance?
How do discounts affect revenue and profit?
Which products have the highest demand?
What are the monthly sales and profit trends?
Which payment methods are most commonly used?
